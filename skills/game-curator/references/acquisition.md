# Acquisition and diagnostics

Inspect the host's actual tools, procedures and permissions. Report each capability as **supported and verified**, **available but not yet tested**, **requires authentication or permission**, **unavailable**, **failed**, or **unknown**. Distinguish existing local files, authenticated Chrome, in-app and isolated browsers, navigation, DOM/accessibility inspection, JavaScript evaluation, internal state access, same-origin requests, returning results, downloads, local files, local execution, public web and uploads. Browser access does not imply authentication, JavaScript, internal state, network requests or downloads. Never expose sensitive browser state in the report.

Use harmless, minimal probes permitted by the host: inspect tool descriptions, open a Steam page if authorized, check a visible sign-in indicator without capturing credentials, inspect a small DOM fragment, and test other capabilities only using their documented procedures and with permission. Do not download a library as a diagnostic. An untested operation is unknown, not unsupported. State which collectors' prerequisites are verified and which fallbacks are possible.

Select methods according to the task: reuse sufficiently recent exports; use appropriate official APIs or authenticated browser access; use a bundled collector only when its operations are permitted; use navigation and DOM inspection; use public information; or ask for a user-provided export. These are preferences, not a rigid sequence. A user can sign in normally. Never request passwords, cookies, tokens or Steam Guard codes, bypass security, alter account state, or send personal data to unrelated endpoints. Explain failures and continue with partial data. Avoid excessive browsing to avoid requesting an existing export.

The bundled collectors are experimental and require page-context JavaScript; they have not been verified against current authenticated Steam pages. A browser's read-only DOM evaluator may not permit scrolling, accessing internal state, network calls or downloading files. Do not paste or run collector code through such a tool. The user can inspect and run it in their own browser console if they choose and the browser allows it. If none of these paths works, accept uploaded exports or conversational evidence; do not fabricate unavailable data.
