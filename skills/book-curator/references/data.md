# Data and identity

`python3 scripts/goodreads_csv.py INPUT.csv OUTPUT.json` normalizes a Goodreads-format CSV locally; output contains original row values, source, processing time, unknown export and observation times, warnings and selected fields. Record actual export or observation time separately when known; processing an old export does not refresh the source evidence. It requires Python 3, creates new output exclusively with owner-only permissions, verifies the written bytes and cleans up its own failed output. Use a private scratch location for task-authorized normalization. Persisting either raw CSV or derived output requires separate raw-cache consent; scratch processing is not persistent caching. It is tested with synthetic fixtures, not a verified live export. It warns on missing or repeated/conflicting Goodreads IDs; it does not scrape, reconcile or deduplicate records. Inspect warnings and source data before use. A CSV export may omit rereads or history; absence is not proof of completeness. Preserve the original export only with separate cache consent.

A record is an observation, not a canonical book. Preserve exact source IDs, title, author, edition, language, format and original metadata, with source, account scope if verified, observation/export date, coverage and warnings. ISBN and ASIN identify editions or products; Goodreads book IDs usually identify editions, while work IDs identify works. Validate identifier context and conflicts; even exact identifiers can be incorrect source data. Distinct edition identifiers can represent the same work without being the same edition. Title and author can suggest a candidate work only, especially with translations, anthologies and duplicate titles. Do not automatically merge records; resolve uncertain candidates with the user or retain separately. Never combine unverified accounts. Retain source observations and disagreements after any user-confirmed relationship.

Ownership, acquisition type (purchase, loan, personal document or unknown), shelf, progress, reading status, rating, review and dates are separate. A `read` shelf is a source assertion, not proof of enjoyment or the full reading history. `My Rating` zero means unrated in the Goodreads export convention; preserve raw zero and normalize it to null, never dislike. Missing, empty, invalid and unknown are not zero. A custom shelf is not necessarily a status. A date added is not a reading date. Do not assume a personal document is a purchased book.
